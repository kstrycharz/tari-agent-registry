# Reporting security issues

Report privately through this repository's Security tab:
https://github.com/kstrycharz/tari-agent-registry/security/advisories/new

If private reporting is unavailable, contact the repository owner privately
through their GitHub profile. Do not open public issues containing secrets,
exploit payloads or wallet data. Enable private vulnerability reporting at launch.

Only the latest active version of an entry is maintained. Deprecated entries
remain visible for advisories and are not recommended for installation.
Read [the security model](docs/security-model.md) before interpreting scan results.
